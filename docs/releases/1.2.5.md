# FinTrack 1.2.5 (Android build 12)

Settings shows the new UPI payments entry point. Scan a payee QR with the camera, choose a QR image, or paste a UPI payment link. Review the payee, amount, category and purpose before opening an installed UPI app. Payment history supports status and evidence filters, manual recording and linking existing expenses.

Payment attempts are saved before handoff. Interrupted app results are retained securely and retried when payment history opens. Manual recording uses stable request keys across retries. Reported payment success remains awaiting confirmation until the user reconciles it. Uploaded statements provide user-supplied reconciliation evidence.

Web Settings shows UPI and AI connector availability. Configured servers expose payment history and statement matching. AI connector grants separately control ledger reads, manual ledger writes and payment-history summaries. Runtime feature flags are evaluated for each request.

Install the APK over the existing application to preserve local records and queued edits. The UPI backend must be enabled on the configured server before payment initiation is available. OAuth connections require the server's identity-provider setup. Authoritative payment verification requires a bank or payment-provider integration.
