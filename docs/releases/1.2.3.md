# FinTrack 1.2.3 (Android build 10)

Fixes a native rendering error in the expanded “Can I spend this?” card. The amount
field’s scroll state is now separate from the section’s expanded state. Removes
expansion dividers and adds consistent spacing. Financial calculations are unchanged.

Settings now includes Check for updates, installed-version display, release status,
connection-error recovery and Download update. It checks the public stable GitHub
release without sending account or ledger data. Only APK links in the FinTrack
repository are accepted. The download opens in the browser; users open the APK and
approve Android installation. No silent installation or automatic downloads occur.

Install this APK once to gain the new Settings update option. Install over the
existing app without uninstalling to retain records and queued changes. The same
private-test signing certificate is retained.

Validation: Flutter analysis, 57 unit/widget tests and Android emulator journeys
passed. Expanded-form screenshots use an isolated local test ledger. Real account
records, financial calculations and sync contracts are unchanged.
