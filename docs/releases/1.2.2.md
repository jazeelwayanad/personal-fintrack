# FinTrack 1.2.2 (Android build 9)

The web and native dashboards now omit the Overview/Budgets switch and the balance
visibility toggle. Balances remain visible; budget management stays available in
Plans. The reporting period and financial definitions remain displayed.

Inputs have more horizontal and vertical padding across authentication, editors,
account details and feedback. Password visibility controls remain available.

Includes the complete native web-style UI and reduced-motion-aware transitions
from 1.2.1: matching colors, Outfit type, borderless cards, dock navigation, account
contact rows, report bars, responsive layouts and subtle press feedback.

Validated with web lint/type/build, 53 Flutter tests, 360/390/430/768px and large-text
layouts, keyboard-visible forms, and Android navigation/payment/account/feedback/
authentication checks. Screenshots use isolated test records unless labelled as
an authenticated local web view. No fixtures or demo records ship in the app.

Install over the existing APK without uninstalling. The existing private-test
signing certificate is retained. Backend contracts, financial calculations,
accounts and queued edits are unchanged. Physical-device gesture/visual review
remains recommended.
