# FinTrack Android 1.2.1 (build 8)

The native application now follows the existing web interface across Home, Plans,
Activity, Reports, Settings, Account, authentication, feedback and record editors.
This is a native presentation update; backend contracts and finance calculations
are unchanged.

- Matching ivory/teal palette, Outfit typography, borderless surfaces, pill inputs,
  pastel quick actions, contact rows and full-destination active navigation pills.
- Web-style Overview/Budgets segment, compact balance breakdown, report totals
  and category bars. Tablet content uses paired columns.
- Header sync, theme and account controls follow the web order. Account photo
  actions live in the avatar editor menu. Navigation retains native Back controls.
- Short page fade/slide transitions, press feedback, dock selection and report
  progress animations. Custom motion respects Android reduced-animation settings.
- Keyboard-visible pages hide the dock and floating transaction action.
- APK retains the existing private-test signing certificate for in-place upgrades.

Validation: Flutter analysis, unit/widget tests including reduced-motion checks,
360/390/430/768px and enlarged-text checks, keyboard-visible editor, plus Android
emulator navigation/payment/account/feedback/authentication screenshot review.
Screenshots use an isolated test ledger; no sample records are shipped.

Install the APK over the existing app without uninstalling. Physical-device
visual and gesture verification remains recommended. No backend or web deployment
is required for this native-only release.
